# Виселица (C++)

Консольная игра «Виселица» с тематическими словарями. Учебная практика.

## Структура
- `include/Dictionary.h` — словарь по категориям
- `include/GameSession.h` — игровой сеанс (маска слова, названные буквы, попытки)
- `data/` — файлы категорий (одно слово в строке, имя файла = категория)
- `src/` — реализация (появится на следующих этапах)
